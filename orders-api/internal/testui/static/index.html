    ¿Y la notificación?

    La API responde 201 en cuanto guarda el pedido y su evento en una sola transacción. El resto ocurre después y en otro servicio: el worker lee el outbox, lo encola en Redis y "envía" la notificación (hoy, una línea de log). Esta página no puede verlo porque la API no expone ese estado; compruébalo así:

    Docker Compose · notificaciones enviadas 
    docker compose logs notifier-worker --no-log-prefix | grep notificación
    Estado del evento en el outbox (pendiente = published_at nulo) 
    docker compose exec postgres psql -U orders -d orders -c "SELECT event_type, published_at IS NOT NULL AS publicado, attempts FROM outbox_events ORDER BY created_at DESC LIMIT 10;"
    Esta página solo existe si ENABLE_TEST_UI=true. En los manifiestos de Kubernetes está apagada.
